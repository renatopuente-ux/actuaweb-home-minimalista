# Home de Actuaria en versión minimalista (demo interna)

El home de [actuaria.com](https://actuaria.com/) con su mismo contenido y orden de secciones, reducido a lo mínimo para compararlo con el sitio real.

**Lo que queda:**
- El logo de Actuaria.
- Los colores de marca: navy `#151F47`, azul `#3061AA` y naranja `#DF5E2D`.
- Dos fotografías: el equipo y el velero.
- Neumorfismo: una sola superficie (`#E8ECF4`) con sombras de luz y sombra.

**Lo que se quitó:**
- Íconos, texturas de fondo y vidrio (liquid glass).
- Videos y GIF.
- Animaciones: escritura del título, contadores, carruseles y efectos al pasar el mouse.
- Logos de clientes, sellos de certificaciones y logos de testimonios. Quedan como texto.
- Fuentes de marca: se usa la tipografía del sistema.

**Detalles:**
- El formulario no envía nada. Los contactos reales llegan por actuaria.com.
- La página tiene `noindex` para que los buscadores no la tomen como contenido duplicado.
